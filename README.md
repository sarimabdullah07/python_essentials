# Upgrade Python Class
A collection of Python practice programs and mini-projects created while learning and improving Python programming concepts. This repository contains examples ranging from basic loops and functions to recursion, lambda functions, billing systems, and simple interactive games.

# 📚 About the Repository
This repository was developed as part of an ongoing Python learning journey. Each file focuses on a specific programming concept and demonstrates practical implementation through small projects and exercises. The goal is to strengthen problem-solving skills and gain hands-on experience with Python fundamentals.

📂 Project Contents
# 1. argument_types.py
Demonstrates different types of arguments used in Python functions, including:

Positional arguments
Keyword arguments
Default arguments
Variable-length arguments
This file helps in understanding how data is passed to functions in different scenarios.

# 2. electricitiy_bill.py
A simple electricity bill calculator that computes the total bill based on electricity consumption units and predefined billing rates. It showcases:

Conditional statements
Mathematical calculations
User input handling

# 3. for_loop.py
Contains examples and exercises related to Python's for loop. It explains:

Iteration through ranges
Loop execution flow
Repetitive task automation

# 4. fruit_guessing_game.py
An interactive guessing game where users try to guess the correct fruit. This project demonstrates:

User interaction
Conditional logic
Basic game development concepts

# 5. function_01.py
Introduces user-defined functions in Python. Topics covered include:

Function creation
Function calling
Returning values
Code reusability

# 6. function_02.py
Additional exercises focused on creating and using functions. This file provides more practice with:

Parameters and arguments
Function organization
Problem-solving using functions

# 7. function_inside_lambda.py
Demonstrates advanced functional programming concepts using:

Lambda functions
Map function
Filter function
Reduce function
This file helps understand concise and efficient data processing techniques.

# 8. guessing_game.py
A number guessing game where the user attempts to find a randomly selected value. Concepts covered:

Loops
Conditions
Random number generation
Interactive programming

# 9. lambda_function.py
Practice examples of Python lambda functions. It explains:

Anonymous functions
Short function expressions
Functional programming basics

# 10. nested_for_loop.py
Examples of nested loops used for pattern printing and grid-based iterations. Topics include:

Loop nesting
Pattern generation
Logical thinking exercises

# 11. recursion_function.py
Demonstrates recursion in Python through practical examples such as:

Factorial calculation
Fibonacci series generation
This file helps understand how functions can call themselves to solve problems.

# 12. resturant_bill.py
A restaurant billing system that calculates:

Order totals
GST charges
Final payable amount
Useful for understanding arithmetic operations and billing logic.

# 13. scopes.py
Explains variable scope in Python, including:

Local scope
Global scope
Scope accessibility rules
This file helps clarify how variables behave in different parts of a program.

# 14. student_data.py
A simple student record management program used to store and process student information and results. Concepts demonstrated:

Data handling
List operations
Basic record management
